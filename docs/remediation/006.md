# MDPS-AUDIT2-006: existing-media provenance

A filename containing `[YouTubeID]` is a locator, not identity evidence.
Existing media is adopted only when a durable binding under
`State/ArchiveMode/MediaBindings` matches all of:

- provider = YouTube
- provider ID
- representation kind
- archive-relative path
- SHA-256 of the current file bytes

Automatic downloads use a unique per-attempt marker so the process can identify
the file produced by that invocation without trusting an unrelated pre-existing
filename. After full technical verification, Archive Mode hashes the result and
writes its binding before marking the representation complete. Normalized media
is bound only after the normalized bytes pass verification.

If a valid but unrelated file is renamed to contain another provider ID, it has
no matching binding and cannot make that historical item complete. A previously
bound file can still be re-adopted after canonical state loss, including when
the source later becomes unavailable, as long as its bytes still match the
recorded digest.
