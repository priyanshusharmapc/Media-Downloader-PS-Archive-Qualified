# MDPS-AUDIT2-003: fork-bound application updates

The qualified publication must never replace itself with the upstream
`mhogomchungu/media-downloader` product through the inherited updater.

Application release discovery is bound to:

`priyanshusharmapc/Media-Downloader-PS-Archive-Qualified`

Automatic application updating defaults to disabled. A user may still enable the
feature, preserving the updater capability, but release discovery remains bound
to this fork.

Before staging an update ZIP, the release asset URL must use HTTPS, must be
hosted through `github.com`, and its path must begin with this repository's
`/releases/download/` namespace. Matching only an asset filename is not
sufficient. This prevents release metadata from redirecting the updater to an
upstream or unrelated package.

A CI regression policy fails if either historical upstream release API is
restored, if automatic application updating defaults to enabled, or if the
release-asset repository binding is removed.
